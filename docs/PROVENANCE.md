# Source provenance

This is an explicit import of existing StockMesh source. Its Git import date is
not the date every file was originally written. Historical crate names are kept;
private repository history is not republished or reconstructed.

StockMesh/Stocklana's core, venue adapters, settlement program and execution host
predate this repository. The import also includes portfolio acquisition/recovery
and an experimental fixed-unit basket vault. Development uses AI-assisted coding
and review; automated checks are not an independent audit.

`SOURCE_MANIFEST.json` records each imported relative path, original digest,
exported digest and packaging transformation. It does not expose operator paths.

This repository excludes web source, internal delivery plans, unrelated machine-
economy/hardware/prediction products, private keys, provider URLs, user records,
production journals, operating runbooks and built deployment binaries.

For competition review, identify the real pre-existing baseline and actual work
completed during the event. The source import alone does not establish a
competition-period contribution or authorship history. See the
[Colosseum FAQ](https://colosseum.com/hackathon).
