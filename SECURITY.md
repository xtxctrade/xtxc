# Security

Report suspected vulnerabilities privately to
[skewlabs@skew.deals](mailto:skewlabs@skew.deals). Do not include customer data,
keys or sensitive infrastructure details in public issues.

The source snapshot has no independent audit claim. The basket vault is
experimental. Audits of third-party venues do not cover XTXC's integration or
custom programs.

Important boundaries include issuer/mint/policy identity, user-authorized
messages, output minima, actual token changes, replay protection and durable
reconciliation of unknown attempts. A publication signature is not trading
authority. Basket-share claims and trading-pool market prices are separate.

Do not perform production writes, denial-of-service tests, deployments, authority
changes or funded exploit tests without separate permission. There is no automatic
bug-bounty promise. The review workflow needs no production credentials.
